# GitHub activity health

The card is generated by `.github/workflows/github-stats.yml` using GitHub’s GraphQL API. The SVG is a saved snapshot: its numbers and grade are regenerated on every successful run, not hand-maintained. Runs are scheduled hourly and also run on pushes to `main` or manual dispatch. GitHub may delay scheduled runs.

- Contributions: `contributionCalendar.totalContributions`.
- Commits: `totalCommitContributions` (GitHub-counted contributions, not every commit on every branch).
- Pull requests: `totalPullRequestContributions`.
- Issues: `totalIssueContributions`.
- Public repositories: `repositories(privacy: PUBLIC, ownerAffiliations: [OWNER]).totalCount`, including owned public forks.

Activity counts cover January 1 at 00:00 UTC through the refresh time. Repository count is the current total, regardless of creation date. GitHub contribution eligibility rules and the token’s access determine what is counted; private activity may be included when visible to the configured token. No private repository names or contents are published.

The workflow uses `SUMMARY_GITHUB_TOKEN` when configured, falling back to `GITHUB_TOKEN` for the health query. A failed query or invalid count fails the step and leaves the published card untouched. Commit/push errors fail the workflow instead of silently reporting success.

## Custom score

This is a personal activity score, not an official GitHub grade or a measure of code quality. Each ratio is capped at 1:

```text
score = round(100 × (
  0.50 × min(contributions / 1500, 1) +
  0.20 × min(commits / 1500, 1) +
  0.20 × min(pull requests / 250, 1) +
  0.10 × min(public repositories / 100, 1)
))
```

Grades: A+ ≥ 90, A ≥ 85, B+ ≥ 75, B ≥ 65, B− ≥ 55, C ≥ 45, D ≥ 30; otherwise F. Issues are displayed but do not contribute separately to the score. These fixed scoring targets are intentional; all activity values come from the API. The score resets with year-to-date activity each January.

API definitions: https://docs.github.com/en/graphql/reference/users

Run regression checks with `node --test tests/health-card.test.cjs` (Node.js 20+).
